GNOME extension for selecting `text-scaling-factor` in Quick Settings.

## How to install

1. [Download](https://github.com/hejathor/gnome-extension-text-scale/releases/latest/download/gnome-extension-text-scale@hejathor.github.com.zip)

2. Run in Terminal:

```
unzip -o ~/Downloads/gnome-extension-text-scale@hejathor.github.com.zip -d ~/.local/share/gnome-shell/extensions/
```

3. Log Off and then log back in.

4. Run in Terminal:

```
gnome-extensions enable gnome-extension-text-scale@hejathor.github.com
```
